### 🚀 Destaque de Engenharia / Featured Project

<table>
  <tr>
    <td>
      <h3 align="left">🛡️ web-sentinel-watchdog</h3>
      <p>
        <strong>Plataforma Full-Stack de Observabilidade e Telemetria em Tempo Real para Servidores Linux VPS, Docker e Nginx.</strong>
      </p>
      <p>
        Desenvolvido para resolver o desafio de monitorar recursos críticos de infraestrutura em ambientes de produção com latência mínima e interface centralizada e reativa.
      </p>
      <p>
        <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python" />
        <img src="https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB" alt="React" />
        <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" alt="TypeScript" />
        <img src="https://img.shields.io/badge/Linux_Ubuntu-E95420?style=flat-square&logo=ubuntu&logoColor=white" alt="Ubuntu" />
        <img src="https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white" alt="Docker" />
        <img src="https://img.shields.io/badge/Nginx-009639?style=flat-square&logo=nginx&logoColor=white" alt="Nginx" />
        <img src="https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white" alt="Vite" />
      </p>
      <details>
        <summary><b>🔍 Ver Arquitetura & Detalhes Técnicos</b></summary>
        <br>
        <ul>
          <li><strong>Daemon de Coleta no Host:</strong> Serviço de telemetria em Python executado no servidor Linux para capturar métricas do kernel (CPU, RAM, I/O de disco e rede).</li>
          <li><strong>Gestão de Containers Docker:</strong> Inspeção da Docker Socket API em tempo real para controle de status, ciclo de vida e consumo de containers.</li>
          <li><strong>Log Analysis & Nginx:</strong> Monitoramento contínuo de status HTTP, requisições de proxy reverso e detecção de anomalias de tráfego.</li>
          <li><strong>Frontend Reativo:</strong> Dashboard moderno construído com React, TypeScript e Vite com atualização contínua e gráficos de telemetria.</li>
          <li><strong>Orquestração:</strong> Deploy conteinerizado via Docker Compose com proxy reverso Nginx otimizado.</li>
        </ul>
      </details>
